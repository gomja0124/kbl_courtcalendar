# 코트 캘린더

2026–27 KBL 정규시즌 270경기를 팀, 경기장, 홈·원정 조건으로 볼 수 있는 웹사이트입니다. 한 번에 여러 팀을 선택할 수 있으며, 팀을 선택하지 않고 경기장만 골라도 해당 장소의 경기가 나옵니다. 월간/목록 보기, 종료 경기 점수, 경기별 선택과 기간 설정을 통한 `.ics` 다운로드를 제공합니다.

월간 경기 칩과 목록의 색상은 항상 **홈 구단**을 기준으로 합니다. 월간 칩은 홈 구단 주색을 약 19% 투명도로 배경에 적용하고 진한 글자를 사용합니다. 10개 구단의 주색은 화면의 색상 안내에서 확인할 수 있습니다.

## 데이터와 이미지

- `../데이터/KBL_전체_2026-2027.ics`에서 일정 270건을 읽습니다.
- `../사진자료/<팀>/로고.svg`의 10개 팀 로고를 복사합니다.
- `python3 build_data.py`를 실행하면 `dist/games.json`과 `dist/assets/logos/`가 갱신됩니다.
- `python3 refresh_results.py`는 공식 KBL API에서 종료 경기 점수를 받아 `dist/results.json`에 비상용 스냅샷으로 저장합니다. 게시된 사이트는 월별 점수를 공식 API에서 다시 조회하며, 연결에 실패하면 이 스냅샷을 보여줍니다.
- 팀 색상은 사용자가 수정한 `구단정보.xlsx`의 HEX 값을 반영했습니다. 배포 시 기준은 `dist/app.js`의 `TEAM_INFO`이며, [Figma 카드뉴스](https://www.figma.com/design/FnF0d6YbTwyqBxsU4x2y77/%EC%9D%B8%EC%8A%A4%ED%83%80-%EB%A7%A4%EA%B1%B0%EC%A7%84st-%EC%B9%B4%EB%93%9C%EB%89%B4%EC%8A%A4-%ED%85%9C%ED%94%8C%EB%A6%BF?node-id=4008-2)는 디자인 참고 자료입니다.

## 실행

프로젝트 폴더에서 `python3 -m http.server 8787 --directory dist`를 실행한 뒤 `http://localhost:8787`을 엽니다. 로컬 정적 미리보기에서는 점수 스냅샷을 사용합니다. 별도 패키지 설치가 필요하지 않습니다.

GitHub 저장소에는 실행에 필요한 `dist/games.json`과 구단 로고가 포함됩니다. `build_data.py`는 원본 일정과 사진자료를 다시 반영할 때 쓰며, 그때는 프로젝트 상위 폴더에 `데이터/`와 `사진자료/`가 있어야 합니다.

게시용 번들은 `python3 build_worker.py`로 만듭니다. `dist/server/index.js`가 화면 파일을 제공하고 공식 KBL 결과 요청을 중계합니다. `.openai/hosting.json`은 Worker 배포를 사용합니다.

일정은 제공된 파일의 2026년 9월 29일 기준 스냅샷입니다. 변경된 경기 일정을 반영하려면 전체 `.ics` 파일을 교체한 뒤 `build_data.py`, `refresh_results.py`, `build_worker.py`를 순서대로 실행해야 합니다. 종료 점수는 사이트에서 약 5분 간격으로 갱신합니다.
